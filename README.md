# IdleNode ($IDLE)

> **Your idle GPU, earning.**
> IdleNode is a decentralized physical infrastructure network (DePIN) for GPU compute. Link your idle GPU to run verified AI workloads (LLMs, image gen, Whisper, agentic tools) and earn $IDLE plus tokenized NVDA yields.
